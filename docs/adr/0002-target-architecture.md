# ADR-0002 · Целевая архитектура карты и конвенции кода

Oct 28, 2026 · @broplz

## Статус

Proposed. Полный аудит (архитектура, баги, производительность, KV, Panorama, изменения Dota
7.34–7.41f) — в отчёте «AOH2Reborn — аудит и план модернизации» (claude.ai, 28.10.2026); здесь
только решения, на которые ссылаются задачи, и правила, которые проверяет `aoh_lint.py`.

## Контекст

Карта — Valve-пример «holdout», переделанный под боссов: ванильный ИИ крипов + datadriven-обёртки
способностей, которые через тикет-систему в `modifier_boss` ставят касты в очередь. Код 2023
года; Dota с тех пор удалила facets, переделала нейтралки (два слота), перенесла значения
талантов внутрь способностей и разбила `npc_heroes.txt` по файлам героев. Сверка с билдом 6968
(26.10.2026): 4 удалённых имени, 156 талантов-оверрайдов, которые, вероятно, ни на что не влияют,
552 записи в формате `AbilitySpecial`.

## Решение 1 — остаёмся на Lua, переписываем инкрементально

Lua с типами и линтером из актуального API-дампа, а не TypeScript→Lua: 36 тыс. строк уже на Lua,
миграция идёт по файлам, каждая фаза заканчивается играбельной картой. Пересмотр — если после
фазы 2 доля возвратов из-за типовых ошибок (nil, сигнатуры) останется высокой.

## Решение 2 — слои

```
Данные (источник истины)   kv-src/*.yaml → tools/kvgen.py → scripts/npc/*.txt (генерируемые блоки)
Контент                    один файл = одна способность/предмет + её модификаторы
Движок боссов              core/boss_queue.lua · telegraph base · phase controller · revenge/counter base
core/                      fx, damage, talents, net (PlayerID), log — без глобалов, через require
```

Целевая структура `vscripts/`: `core/`, `base/` (ability_base, modifier_base), `heroes/<hero>/`,
`bosses/_shared/` + `bosses/<boss>/` + `bosses/ports/aghanim/`, `items/<group>/`, `skills/`,
`modifiers/{generic,difficulty,stats,structures}/`. Переезд файлов — фаза 4, после того как
ядро боссов стабилизировано.

## Решение 4 — конвенции (их проверяет `scripts/agents/aoh_lint.py`; текст для агентов — `.claude/skills/aoh-rules/SKILL.md`)

### Lua
1. Нет глобалов: `local` везде; глобальны только классы для движка (`modifier_x = class({})`), по одному файлу-владельцу, и `Activate`/`Precache`. Хелперы — модули через `require`.
2. Один файл = одна способность/предмет + её модификаторы; имя файла = имя в KV; `LinkLuaModifier` один раз, в файле-владельце, путь через `/` с `.lua`.
3. Числа живут в KV `AbilityValues`; таланты объявляются инлайн в KV, никаких `FindAbilityByName("special_bonus_…")` и `GetLevelSpecialValueFor`.
4. Enum'ы вместо магических чисел: `bit.band(flags, DOTA_DAMAGE_FLAG_*)`, `DOTA_ITEM_NEUTRAL_ACTIVE_SLOT`/`_PASSIVE_SLOT`, `DOTA_UNIT_ORDER_*`; `DOTA_ATTRIBUTE_ALL` — четвёртый атрибут, не «иначе INT».
5. `IsServer()` в начале серверных обработчиков; клиентские события читают `keys.PlayerID` и проверяют владение юнитом.
6. Хендлы умирают: `IsNull()`/`IsAlive()` для всего, что пришло из таймера или события; таймеры и think останавливаются в `OnDestroy`.
7. Каждый `CreateParticle` освобождается (`core/fx.lua`); каждый луп-звук имеет `StopSoundOn`.
8. Событийные обработчики модификаторов фильтруют `self:GetParent()` первой строкой.
9. Think ≥ 0.1 с без обоснования в комментарии; без `FindUnitsInRadius` на каждый тик без нужды; без `print` в горячих путях.
10. Способности боссов — через очередь кастов (`modifier_boss:Submit`), не через тикеты `generic.lua` и не через polling на Timers; новых `ability_datadriven` нет.

### KV
- Новые и мигрированные записи — `AbilityValues`; `ScriptFile` через `/`, файл существует; без дублей ключей и записей; ванильные имена существуют в текущем билде (`vanilla_diff`); у каждой видимой способности/предмета — тултип в `addon_english.txt`; сгенерированный KV правится в источнике.

### Panorama
- Исходники только в `content/…/panorama/`; `*_c` не правятся; никакого доступа к дереву HUD Valve по id и захардкоженных enum'ов; payload клиента без player id.

## Решение 5 — очередь кастов боссов

`core/boss_queue.lua` (есть, 6 тестов): один think 0,1 с на босса; заявка `{prio, deadline,
telegraph(job)→сек, cast(job)→bool, cast_timeout, iterations, on_cancel}`; приоритет + FIFO;
просроченные заявки отменяются; каст без подтверждения заканчивается по `cast_timeout`
(вечных lock'ов нет); lockout — счётчик ссылок с идемпотентным release; `clear()` в `OnDestroy`
гасит частицы и dummy. Подтверждение — `queue:confirm()` из `OnSpellStart` целевой способности,
без глобального `OnAbilityExecuted`. `modifier_boss` держит очередь (задача 0013); обёртки
`generic_*` переводятся на базовый класс телеграфа (0014); `boss_*_init` → контроллер фаз (0015).

## Границы

Не трогаем до p6: баланс, контент, карта (`.vmap`), ассеты. Порт Aghanim's Labyrinth
(`boss_aghanim_*`) изолируем в `bosses/ports/aghanim/` и мигрируем последним. Монетизации нет
(правила Valve 17.08.2023).
